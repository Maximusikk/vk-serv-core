# VKTurn — VPN, который не блокируют

Трафик клиентов идёт через реле VK и неотличим от обычного звонка. Сервер ставится одной
командой, подписки покупателям выдаются ссылкой.

## Что понадобится

- VPS: Ubuntu 20.04+ или Debian 10+, доступ root по SSH
- Ссылка на звонок VK без пароля: ВКонтакте → Звонки → Создать звонок → Конференция
  (выглядит так: `https://vk.com/call/join/XXXX`)
- Приложение-админка (APK)

## 1. Установка сервера

На VPS под root:

```bash
curl -s https://raw.githubusercontent.com/Maximusikk/vk-serv-core/main/install.sh | sudo bash
```

Скрипт спросит ссылку VK-звонка. Если запускаете не из терминала:

```bash
VK_LINK='https://vk.com/call/join/XXXX' sudo -E bash install.sh
```

В конце установки будут напечатаны:

- `VKTURN_ADMIN_TOKEN` — токен админ-приложения (никому не показывайте)
- `VKTURN_MASTER_TOKEN` — токен мастера
- `VKTURN_ADMIN_PIN` — пин сертификата API

Скрипт сам откроет порты: `56000/udp` (основной), `56001–57000/udp` (порты ключей),
`7000/tcp` (API, только HTTPS). Если у хостинга есть файрвол в панели — откройте их и там.

## 2. Настройка админки на телефоне

1. Установите APK-админку
2. «Мои серверы» → «+ Добавить сервер» → **«Настроить по SSH»**
3. Введите IP VPS, порт (22), логин (root), пароль и ссылку VK-звонка → «Подключиться и установить»

Приложение само поставит сервер и добавит его в список. Токен и пин из п. 1 нужны, если сервер
уже установлен вручную: шестерёнка → «Администрирование сервера» → URL API, пин, admin-токен.

## 3. Продажа подписок

1. Шестерёнка → «Открыть панель управления»
2. Вкладка «Подписки» → «Новая»: название, лимит ГБ, срок в днях
3. У подписки — «Копировать ссылку» или «Поделиться» → отправьте покупателю

Покупатель нажимает ссылку — приложение открывается и добавляет подписку само. Один ключ =
одно устройство; лимит и срок видны покупателю в приложении.

## 4. Обновление сервера

```bash
curl -fsSL https://raw.githubusercontent.com/Maximusikk/vk-serv-core/main/upgrade.sh | sudo bash
```

Ключи, база и настройки сохраняются.

## 5. Если что-то не так

```bash
systemctl status vkturn-api vkturn-server vkturn-hy2
journalctl -u vkturn-api -n 50
```
