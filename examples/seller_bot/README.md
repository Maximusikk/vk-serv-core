# Референс-бот продавца VKTurn — кластерный режим (этап 2C)

Telegram-бот (Python 3.10+, aiogram 3), который продаёт подписку сразу на **несколько
серверов** VKTurn: покупатель получает одну `vkturn://bundle`-ссылку на все серверы, бот
считает суммарный трафик и отзывает подписку везде при исчерпании лимита. Оплаты в нём
**нет**: это каркас — свою платёжку подключайте в `may_purchase()` в `bot.py`.

Для старого однонодового сценария см. `SELLER_GUIDE.md` (`docs/`, `../../docs/`).

## Как подключить 3 сервера к боту

### 1. Установите сервер на каждой ноде

На каждом из трёх серверов выполните установку (см. репозиторий vk-serv-core):

```bash
bash install.sh   # github.com/Maximusikk/vk-serv-core
```

После установки `install.sh` (и позднее `upgrade.sh`) печатает:

```
VKTURN_MASTER_TOKEN=...
VKTURN_ADMIN_PIN=...
```

Их и берём: `VKTURN_MASTER_TOKEN` — токен мастера для этой ноды, `VKTURN_ADMIN_PIN` —
SPKI-пин её TLS-сертификата. Если установка была давно и вывод потерялся — выполните
`upgrade.sh`, он перевыполнит печать токена; пин также лежит в `/opt/vkturn/config.txt`
(строка `TLS_PIN=`).

### 2. Задайте переменные окружения бота

| Переменная | Обязательна | По умолчанию | Смысл |
|---|---|---|---|
| `BOT_TOKEN` | да | | токен Telegram-бота от @BotFather |
| `ADMIN_IDS` | да (для покупок) | пусто | Telegram-id продавцов через запятую; `/buy` только для них |
| `NODES` | да | | ноды через `;`, каждая — `host:port\|pin\|MASTER_TOKEN\|имя` (имя опционально) |
| `DB_PATH` | нет | `seller_bot.db` | SQLite бота: заказы, счётчики трафика, курсоры кластера |
| `DEFAULT_DAYS` | нет | `30` | срок подписки по умолчанию |
| `DEFAULT_GB` | нет | `10` | лимит ГБ по умолчанию |

Пример `NODES` на 3 ноды:

```
NODES=203.0.113.10:7000|a1b2...|mt_токен_ноды_1|Нода 1;203.0.113.11:7000|c3d4...|mt_токен_ноды_2|Нода 2;203.0.113.12:7000|e5f6...|mt_токен_ноды_3|Нода 3
```

Пример `.env` (не коммитится, добавьте в `.gitignore`):

```
BOT_TOKEN=123456:ABC...
ADMIN_IDS=123456789
NODES=203.0.113.10:7000|<hex64>|<MASTER_TOKEN>|Нода 1;203.0.113.11:7000|<hex64>|<MASTER_TOKEN>|Нода 2;203.0.113.12:7000|<hex64>|<MASTER_TOKEN>|Нода 3
DB_PATH=seller_bot.db
DEFAULT_DAYS=30
DEFAULT_GB=10
```

Запуск:

```bash
cd examples/seller_bot
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
set -a; . ./.env; set +a
python bot.py
```

Без валидных `NODES` бот не стартует.

### 3. Как это работает

- **`/buy <order_id> [дней] [ГБ]`** → `Cluster.create_everywhere()`: ключ с одним
  `external_id` создаётся на всех нодах (идемпотентно — повтор с тем же `order_id`
  не создаёт дубликатов). Затем `Cluster.bundle()` собирает `vkturn://bundle`-ссылку
  (формат — `_review/00d_protocol_map.md` §1.3 в репозитории C:\Core), и юзер получает её
  моноширинным блоком с подписью «Подписка „имя“: серверов X/Y, лимит Z ГБ, срок N дней».
- **Частичный успех**: если часть нод недоступна, подписка выдаётся по доступным, ошибки
  нод перечисляются админам. Повторный `/buy` с тем же `order_id` добирает недостающие ноды.
- **Локальный стоп-кран**: `local_limit` на каждой ноде равен общему лимиту — если бот
  упал и перестал считать трафик, ноды сами остановят ключ при исчерпании лимита.
- **Фоновый учёт**: раз в 60 с бот забирает `Cluster.usage_all()` дельты по курсорам
  (курсор двигается только после полного успешного забора — дельты не теряются и не
  задваиваются) и складывает в свою SQLite. При `used >= limit` бот делает
  `Cluster.revoke_everywhere()`, помечает заказ отозванным и уведомляет админов.
- **`/status [order]`** (для админов): сколько нод отвечает, used/limit по каждому
  заказу, отозван ли.

### Безопасность

- **master-token** каждой ноды авторизует только `/admin/keys*`, `/admin/usage`,
  `/admin/health` — обычные клиентские endpoints ему недоступны.
- **Пин обязателен**: TLS-пин ноды (`VKTURN_ADMIN_PIN`/`TLS_PIN=`) проверяется до
  отправки токена; пин не совпал — ни одного байта HTTP не уходит. Режима «без проверки» нет.
- Токены и пины **не в git** и не пишутся в логи: держите их в `.env` (права `600`),
  для systemd — `EnvironmentFile=`.
